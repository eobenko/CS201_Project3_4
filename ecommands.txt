At the start of every coding session:
git pull
git fetch origin
git reset --hard origin/main


For updating everything:
git add .
git commit -m "Updated project"
git push


For updating only one file:
git add nameFile.cpp
git commit -m "Updated nameFile"
git push


For updating only specific files:
git add nameFile1.cpp nameFile2.cpp nameFile3.cpp
git commit -m "Updated nameFile"
git pull --rebase origin main
git push





For running just the visual file:
g++ -std=c++20 main.cpp visuals.cpp hospital.cpp patient.cpp doctor.cpp person.cpp -o hospital -lsfml-graphics -lsfml-window -lsfml-system && ./hospital
